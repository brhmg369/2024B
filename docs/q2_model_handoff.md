# 第二问模型交接说明

## 1. 本次修正重点

第二问中，“报废/拆解”的对象是不合格成品，不是零配件。零配件没有主动报废这个独立决策。

拆解后的零配件需要重复步骤 (1) 和步骤 (2)。步骤 (1) 对零配件只有两种处理方式：

1. 检测：若检测出不合格零配件，则丢弃；合格零配件进入装配。
2. 不检测：该零配件直接进入装配环节。

因此，不能用截断式回收价值公式作为拆解后零配件的通用处理公式。这类写法会把零配件处理误写成“可自行舍弃”的选择，但题目不允许零配件主动报废。只有检测出的不合格零配件才能被丢弃。

## 2. 决策变量

严谨模型采用 7 个二元决策变量：

```tex
x_1,x_2,y,z,r_1,r_2,y_r\in\{0,1\}.
```

含义如下：

- \(x_1,x_2\)：首次装配前是否检测零配件 1、零配件 2。
- \(y\)：首次成品是否检测。
- \(z\)：不合格成品是否拆解。
- \(r_1,r_2\)：拆解后零配件 1、零配件 2 是否检测。
- \(y_r\)：拆解后重新装配成品是否检测。

拆解后的零配件策略为：

```tex
r_i=1：检测后进入装配，检测出的不合格件丢弃；
```

```tex
r_i=0：不检测，直接进入装配。
```

如果某零配件在首次装配前已经检测合格，则拆解后仍可视为合格件，因为题目说明拆解不会损坏零配件。因此这种零配件拆解后不需要重复检测，重复检测是被占优的。

## 3. 指标与求解思路

本仓库采用的核心指标为：

```tex
\Pi = S - E
```

其中 \(S\) 是市场售价，\(E\) 是为了最终交付 1 件合格成品所需承担的期望成本。最终选择期望利润最大的策略。

局部判断仍然可以用于解释。例如在给定首次零配件检测策略后，可以计算首次成品不合格概率 \(q_0\)，并用

```tex
t_f<q_0L
```

判断成品检测是否具有局部优势。

但是，对于拆解后首次未检测的零配件，质量是不确定的。若不检测直接进入装配，会改变下一轮成品不合格概率，并可能造成连环调换、拆解和再装配损失。因此，拆解后的零配件不能只用局部回收价值判断，必须进入后续生产流程的期望成本递推。

一句话概括：

```tex
\boxed{\text{局部判断可以减少枚举数量，但最终最优策略仍要靠总期望利润比较。}}
```

## 4. 状态递推模型

程序用状态递推/马尔可夫期望成本模型计算每个策略。

零配件状态包括：

- `none`：无可用件，需要重新购买。
- `known_good`：已知合格件，可直接进入装配。
- `unknown_good`：质量未知但实际合格。
- `unknown_bad`：质量未知且实际不合格。

状态还包括阶段：

- `phase=0`：首次生产阶段，成品检测决策用 \(y\)。
- `phase=1`：拆解后的重复生产阶段，成品检测决策用 \(y_r\)。

对每个状态建立递推方程：

```tex
E(s_1,s_2,\tau)
=
C(s_1,s_2,\tau)
+
\sum P(s_1',s_2',\tau'\mid s_1,s_2,\tau)E(s_1',s_2',\tau').
```

联立所有可达状态方程，求解初始状态：

```tex
E(\varnothing,\varnothing,0).
```

若某策略导致未检测坏件反复进入装配，线性方程组无有限解，则程序标记为不可行或无穷成本，不让程序崩溃。

## 5. 程序对应关系

程序文件：

```text
programs/q2_decision_model.py
```

运行：

```powershell
python programs/q2_decision_model.py
```

输出：

```text
programs/results/q2_policy_results.csv
programs/results/q2_best_policies.csv
```

`q2_policy_results.csv` 包含所有策略及其指标。

主要字段：

- `case`: 表 1 中的情况编号。
- `x1`, `x2`: 首次装配前是否检测零配件。
- `y`: 首次成品是否检测。
- `z`: 不合格成品是否拆解。
- `r1`, `r2`: 拆解后零配件是否检测。
- `yr`: 拆解后重新装配成品是否检测。
- `initial_product_defect_prob_q`: 首次成品不合格概率。
- `qL_minus_tf`: 首次成品检测的局部判断指标。
- `feasible`: 是否有有限期望成本。
- `dominated_reinspection`: 是否存在已知合格零配件拆解后重复检测的被占优行为。
- `expected_cost`: 交付 1 件合格成品的期望成本。
- `expected_profit`: 交付 1 件合格成品的期望利润。

`q2_best_policies.csv` 保留每种情况的最优可行且非占优策略。

## 6. 论文写作建议

论文手可以按下面顺序写第二问：

1. 定义 7 个二元决策变量。
2. 定义期望成本 \(E\) 和期望利润 \(\Pi\)。
3. 说明首次零配件检测的期望成本公式。
4. 用 \(t_f<q_0L\) 说明成品检测的局部判断思想。
5. 强调拆解后零配件不能主动报废，必须检测或直接进入装配。
6. 建立拆解后零配件状态，并写出期望成本递推方程。
7. 枚举策略，求解线性方程组，比较期望利润。
8. 用表格展示 6 种情况的最优策略、期望成本和期望利润。

- 第二问决策流程图；
- 每种情况最优期望利润柱状图；
- 每种情况候选策略期望利润对比图；
- 状态递推示意图。
