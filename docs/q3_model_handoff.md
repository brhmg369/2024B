## 2. 16 位编码含义

策略编码为：

```text
X = x1 x2 ... x16
```

对应关系：

| 位数 | 含义 |
|---:|---|
| x1-x8 | 零配件 1-8 是否检测 |
| x9-x11 | 半成品 1-3 是否检测 |
| x12-x14 | 不合格半成品 1-3 是否拆解 |
| x15 | 成品是否检测 |
| x16 | 不合格成品是否拆解 |

其中 1 表示“检测/拆解”，0 表示“不检测/不拆解”。

## 3. 生产逻辑

模型严格按题意处理：

- 零配件没有主动报废或拆解决策。
- 零配件若检测，检测出不合格则丢弃，合格进入装配。
- 零配件若不检测，直接进入装配。
- 拆解决策只作用于不合格半成品或不合格成品。
- 拆解不会损坏内部零部件，回流后保留原真实质量状态，不重新抽样。
- 若任一下级输入不合格，则上级产品必不合格。
- 只有全部下级输入合格时，上级才以题目给定次品率产生额外装配缺陷。
- 不检测成品且成品不合格时，产生调换损失，并按成品拆解决策处理退回产品。

## 4. 数学模型

对固定策略 \(X\)，程序建立有限状态马尔可夫奖励过程。状态记录 8 个零配件和 3 个半成品的状态：

```text
N  = 当前无该对象
KG = 已知合格
UG = 未检测但实际合格
UB = 未检测且实际不合格
```

令 \(V_X(S)\) 表示从状态 \(S\) 出发最终交付 1 件合格成品的期望成本，则：

```tex
V_X(S)
=
C_X(S)
+
\sum_{S'}P_X(S'\mid S)V_X(S').
```

联立所有可达状态：

```tex
(I-P_X)V_X=C_X.
```

期望利润：

```tex
E[\Pi(X)]=R-V_X(S_0).
```
