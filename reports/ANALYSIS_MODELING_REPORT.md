# 问题一与问题二分析建模报告

## 1. 问题拆解

供应商声称一批零配件的次品率不超过标称值。企业希望用尽可能少的检测次数，在两种不同信度下作出接收或拒收判断。标称次品率为

\[
p_0=0.10.
\]

本问题不是对样本次品率与 `10%` 作简单比较，而是两个方向相反的精确单侧检验：

- 拒收检验：若有至少 95% 的信度认为实际次品率超过 `p0`，拒收该批；
- 接收检验：若有至少 90% 的信度认为实际次品率不超过 `p0`，接收该批；
- 两项证据均不足时，输出“证据不足”，不能强行二分。

### 1.1 输入、变量和输出

| 类型 | 符号 | 含义 |
| --- | --- | --- |
| 输入 | `p0` | 标称次品率，默认 0.10 |
| 输入 | `gamma_R` | 拒收信度，默认 0.95 |
| 输入 | `gamma_A` | 接收信度，默认 0.90 |
| 输入 | `n` | 固定抽取的零配件数量 |
| 输入 | `N` | 批次总体量；未知时只使用二项模型 |
| 观测 | `X=x` | 样本中的次品数 |
| 派生 | `alpha_R=1-gamma_R` | 拒收检验显著性水平，默认 0.05 |
| 派生 | `alpha_A=1-gamma_A` | 接收检验显著性水平，默认 0.10 |
| 输出 | `a_n` | 接收临界值，`x <= a_n` 时接收 |
| 输出 | `r_n` | 拒收临界值，`x >= r_n` 时拒收 |

目标是在尾概率约束成立的前提下，分别寻找首次可能接收、首次可能拒收以及首次同时存在接收域和拒收域的最小 `n`。对指定 `n`，程序给出完整三态判定区间。

### 1.2 子问题依赖

1. 先由信度得到两个显著性水平；
2. 再由抽样机制选择二项分布或超几何分布；
3. 计算左右尾概率并确定临界值；
4. 搜索满足不同“最小”口径的样本量；
5. 最后进行边界校核和灵敏度分析。

预期图表包括样本量—临界次品数曲线、信度—最小样本量阶梯图，以及二项/超几何阈值对比表。

## 2. 假设敏感性预检

### 2.1 模糊表述及解释

| 模糊点 | 解释 A | 解释 B | 对结果的影响 |
| --- | --- | --- | --- |
| “尽可能少” | 只要求某一极端样本结果能作出结论 | 要求同一个固定 `n` 同时存在接收域和拒收域 | 前者拒收最小值会非常小；后者给出可实际执行的统一抽样数 |
| 总体量 `N` | 批次很大或视为独立同分布抽样 | 有限批次内无放回抽样 | 分别对应二项与超几何分布 |
| “在 90% 信度下不超过” | 检验 `p >= p0` 并用左尾证据拒绝 | 只看样本率 `x/n <= p0` | 后者没有控制错误概率，不能采用 |
| 抽样过程 | 预先固定 `n` 后只检验一次 | 每多抽一个样品就重复同一阈值检验 | 后者产生多重窥探并放大总体误判率 |
| 有限总体标称值 | 允许的次品数为 `floor(N p0)` | 对 `N p0` 四舍五入 | 四舍五入可能允许总体次品率超过标称值 |

### 2.2 快速验算与递进性检查

- 二项模型在 `n=1` 时，即使检出 1 个次品，右尾概率仍为 `0.1>0.05`；没有任何可拒收结果。
- 在 `n=2` 时，若 2 个全为次品，右尾概率为 `0.1^2=0.01<=0.05`，因此首次存在拒收域。但这种方案只有极端样本才触发拒收，不能代表高检验功效。
- 接收方向最有利的样本结果是 `x=0`。需满足 `0.9^n<=0.10`，故 `n>=22`；`n=21` 尚不满足，说明首次接收样本量为 22。
- 在 `n=22` 时，`P(X<=0)=0.098477`；而 `P(X>=6)=0.018216<=0.05`、`P(X>=5)=0.062134>0.05`。因此同一固定样本方案为：`x=0` 接收，`x>=6` 拒收，`1<=x<=5` 证据不足。
- 超几何模型在 `n=N` 时退化为全检：`x<=floor(Np0)` 接收，`x>=floor(Np0)+1` 拒收，不应再有不确定区。
- 当 `N` 增大且抽样比例 `n/N` 变小时，超几何结果应逐渐接近二项结果。
- 提高任一信度会降低相应显著性水平，使判定更严格；相应临界区不会反向放宽。

### 2.3 最终采用的解释

采用“预先固定样本量、一次性检验”的口径。二项分布是题面未给出 `N` 时的主模型；已知 `N` 且为无放回抽样时，使用超几何分布作精确有限总体修正。统一方案的“最小抽样次数”取首次同时存在接收域与拒收域的 `n`；同时保留首次可接收和首次可拒收两个辅助指标，以完整说明“尽可能少”的歧义。

### 2.4 绘制的图像和对比表格

- `figures/q1_decision_boundaries.pdf`：不同样本量下的接收与拒收临界值；用于观察不确定区宽度。
- `figures/q1_confidence_sensitivity.pdf`：信度变化对最小样本量的影响；用于检验结论稳健性。
- `results/q1_thresholds.csv`：每个样本量的临界值及临界尾概率。
- `results/q1_summary.json`：关键参数、最小样本量、指定观测值判定和一致性校核。
- `results/q1_sensitivity.csv`：信度扰动结果。

## 3. 模型假设

1. 每个零配件只能被判为合格或次品，检测结果准确；否则需另行引入检测误判率。
2. 二项主模型下，各次检测在给定真实次品率 `p` 时相互独立且同分布，或抽样比例足够小，可以忽略有限总体修正。
3. 超几何模型下，总体大小 `N` 已知，从同一批次均匀、无放回抽取 `n` 个零配件。
4. 抽样方案中的 `n` 和判定阈值在看到数据前确定，整个固定样本方案只执行一次。
5. 不引入未由题面给出的备择次品率和检验功效，因此不把本模型解释为传统的功效样本量设计。

## 4. 二项分布主模型

### 4.1 拒收规则

建立单侧假设

\[
H_{0R}:p\le p_0,\qquad H_{1R}:p>p_0.
\]

在边界 `p=p0` 下，样本次品数满足

\[
X\sim\operatorname{Bin}(n,p_0).
\]

由于右尾概率随 `p` 单调增加，复合原假设内最不利点为 `p0`。定义拒收临界值

\[
r_n=\min\left\{x:\Pr_{p_0}(X\ge x)
=\sum_{k=x}^{n}{n\choose k}p_0^k(1-p_0)^{n-k}
\le \alpha_R\right\}.
\]

若集合非空且观测到 `x>=r_n`，则以不低于 `gamma_R` 的信度拒收。

### 4.2 接收规则

建立反向单侧假设

\[
H_{0A}:p\ge p_0,\qquad H_{1A}:p<p_0.
\]

左尾概率在 `H0A` 内的最大值同样取在边界 `p0`。定义接收临界值

\[
a_n=\max\left\{x:\Pr_{p_0}(X\le x)
=\sum_{k=0}^{x}{n\choose k}p_0^k(1-p_0)^{n-k}
\le \alpha_A\right\}.
\]

若集合非空且观测到 `x<=a_n`，则以不低于 `gamma_A` 的信度接收。

### 4.3 三态判定与约束

\[
\operatorname{Decision}(x)=
\begin{cases}
\text{接收}, & x\le a_n,\\
\text{拒收}, & x\ge r_n,\\
\text{证据不足}, & a_n<x<r_n.
\end{cases}
\]

程序必须验证 `a_n<r_n`，并分别核对临界点满足尾概率约束、相邻非临界点不满足约束。

## 5. 超几何有限总体修正

设总体中实际次品数为 `D`，允许的最大次品数取

\[
D_0=\lfloor Np_0\rfloor,
\]

于是最小不可接受次品数为 `D1=D0+1`。无放回抽样时

\[
\Pr(X=k\mid N,D,n)
=\frac{{D\choose k}{N-D\choose n-k}}{{N\choose n}}.
\]

拒收检验使用可接受总体边界 `D0`：

\[
r_{n,N}=\min\left\{x:\Pr_{D_0}(X\ge x)\le\alpha_R\right\}.
\]

接收检验需要排除所有 `D>=D1` 的总体，左尾最不利点为 `D1`：

\[
a_{n,N}=\max\left\{x:\Pr_{D_1}(X\le x)\le\alpha_A\right\}.
\]

这两个边界分别控制“错拒合格批”和“错收不合格批”的概率。若题面没有给出 `N`，不得用任意示例 `N` 替代正式数据；程序保留 `--population-size` 参数，待 `N` 确认后立即重算。

## 6. 最小样本量口径

定义

\[
n_R=\min\{n:r_n\text{ 存在}\},\qquad
n_A=\min\{n:a_n\text{ 存在}\},
\]

以及统一固定样本方案

\[
n_*=\min\{n:a_n\text{ 与 }r_n\text{ 同时存在且 }a_n<r_n\}.
\]

在默认二项参数下，解析预检得到 `nR=2`、`nA=22`，从而 `n*=22`。其中 `nR=2` 只说明“存在一个极端拒收结果”，不代表这一方案对略高于 10% 的次品率具有足够功效。

## 8. 验证与灵敏度方案

1. 概率校验：每个分布向量非负且总和在浮点容差内等于 1。
2. 默认值校验：`n=22` 时接收阈值为 0、拒收阈值为 6。
3. 相邻点校验：接收临界值后一项必须超过 `alpha_A`；拒收临界值前一项必须超过 `alpha_R`。
4. 全检校验：超几何 `n=N` 时应精确区分 `D0` 与 `D1`。
5. 渐近校验：固定较小 `n`，增加 `N` 后超几何临界值应与二项临界值相同或接近。
6. 信度灵敏度：在拒收信度 `0.90--0.99`、接收信度 `0.80--0.99` 的预设网格上重算最小样本量。
7. 总体量灵敏度：仅在超几何模式下比较不同 `N`；明确其为模型性质展示，正式结论随实际 `N` 更新。

## 9. 固定样本方案的适用边界

当前模型不允许在 `n=1,2,3,...` 上持续窥探并反复使用同一 `alpha`。如果企业希望“抽到足够证据就立即停止”，需要另行建立带总体错误率控制的序贯检验，例如预先分配各阶段 alpha 或在给定备择次品率后建立 SPRT。该扩展与本轮固定样本程序不能混为一谈。

## 10. 问题二：联合信念状态 MDP

### 10.1 任务与旧模型修正

问题二需要依据当前质量信息选择购件、零配件检测、装配、成品检测和不合格品拆解动作，使最终交付一件合格成品的期望成本最小。拆解后的零配件会重新进入生产流程，且未检测质量不可观察，因此预先固定 `(x1,x2,y,z,r1,r2,yr)` 会限制后续动作不能随新信息改变。

远端最新模型把该问题修正为联合信念状态 MDP。固定七变量策略仍可作为受限基准，但不再作为正式模型。该变更属于全局替换，论文中的问题二公式、结果、图表和结论均需同步回溯。

### 10.2 状态、动作与输出

| 类型 | 对象 | 含义 |
| --- | --- | --- |
| 隐状态 | `omega_i in {N,G,B}` | 部件 `i` 缺失、实际合格或实际不合格 |
| 信念状态 | `b(omega1,omega2)` | 给定已有观测的两部件联合质量分布 |
| 动作 | buy/test/assemble | 购件并检测、购件不检测、检测在手件、四类装配处置 |
| 观测 | 检测结果、成品是否合格 | 用于条件化或贝叶斯更新联合信念 |
| 目标 | `V(b0)` | 交付一件合格成品的最小期望成本 |
| 输出 | `pi*(b)` | 每个可达信念状态下的最优动作 |

联合信念而非两个独立边际是必要的：观察到成品不合格后，两部件质量在后验上相关，检测其中一个部件的价值取决于另一个部件的联合概率。

### 10.3 核心模型

若两个部件均在手，成品合格概率为

\[
P_G(b)=b(G,G)(1-p_f),\qquad P_D(b)=1-P_G(b).
\]

装配动作 `A_yz` 的一步期望成本为

\[
C(b,A_{y,z})=c_a+yt_f+P_D(b)[(1-y)L+zd].
\]

拆解时根据缺陷观测更新信念：

\[
b'(\omega_1,\omega_2)
=\frac{b(\omega_1,\omega_2)P(D\mid\omega_1,\omega_2)}{P_D(b)}.
\]

Bellman 方程为

\[
V(b)=\min_{a\in\mathcal A(b)}
\left[C(b,a)+\sum_{b'}P(b'\mid b,a)V(b')\right].
\]

最终期望利润为 `Pi=S-V(b0)`。

### 10.4 求解与验证计划

1. 从初始状态 `(N,N)` 生成所有可达信念与可行动作。
2. 将信念概率保留 6 位后合并近似状态，以控制有限状态规模。
3. 用 Gauss--Seidel 值迭代求解，更新阈值为 `1e-10`。
4. 输出状态策略、所有动作 `Q` 值、每轮最大更新量和最终 Bellman 残差。
5. 用 4--7 位信念合并精度重算六种情形，检查成本结论是否稳定。
6. 分别把三类次品率同比缩放、调换损失和拆解成本乘以 `0.8--1.2`，记录利润与策略切换。
7. 与 Git `53166ac` 的固定七变量受限策略比较，验证新策略的成本不高于受限基准。

### 10.5 Figure Plan

- `[RESULT] Q2-POLICY`：六种情形从初始状态到首次缺陷后的最优动作路径，证明状态策略如何映射为业务动作。
- `[VALIDATE] Q2-VALIDATION`：值迭代更新量与信念离散精度，验证求解停止与状态合并误差。
- `[SENS] Q2-SENSITIVITY`：次品率、调换损失和拆解成本扰动下的期望利润，识别敏感参数和策略切换。

## 11. 问题三：多工序生产期望递推模型与遗传算法

### 11.1 任务与结构

问题三把问题二的单级装配扩展为两工序、8 个零配件、3 个半成品和 1 个成品的生产结构：

\[
\{1,2,3\}\to H_1,\qquad
\{4,5,6\}\to H_2,\qquad
\{7,8\}\to H_3,\qquad
\{H_1,H_2,H_3\}\to F.
\]

表 2 给出全部零配件次品率（均为 10%）、购买单价与检测成本，半成品次品率（均为 10%）、装配成本、检测成本与拆解费用，以及成品次品率（10%）、装配成本、检测成本、拆解费用、市场售价 200 元和调换损失 40 元。要求给出各环节“是否检测、是否拆解”的决策方案并给出期望指标。

### 11.2 决策编码与状态

策略编码为 16 位二元向量

\[
X=(x_1,\ldots,x_{16}),\qquad x_i\in\{0,1\},
\]

其中 `x1--x8` 为零配件是否检测，`x9--x11` 为半成品是否检测，`x12--x14` 为不合格半成品是否拆解，`x15` 为成品是否检测，`x16` 为不合格成品是否拆解；1 表示检测/拆解，0 表示不检测/不拆解。搜索空间为 `2^16=65536`。

对每个零配件和半成品维护四态 `{N,KG,UG,UB}`：`N` 表示当前无该对象，`KG` 表示已知合格，`UG`/`UB` 分别表示未检测但实际合格/不合格。零配件没有主动报废或拆解决策；检测出的不合格零配件被丢弃后重复购检直至得到合格件。拆解只作用于不合格半成品或不合格成品，且拆解不损坏内部零部件，回流件保留原真实质量状态、不重新抽样。若任一下级输入不合格，则上级产品必不合格；仅当所有下级输入合格时，上级才以给定次品率产生装配缺陷。

### 11.3 固定策略期望递推

对固定策略 `X`，设 `V_X(S)` 为从状态 `S` 出发最终交付 1 件合格成品的期望成本。每个状态建立一步期望成本与转移：

\[
V_X(S)=C_X(S)+\sum_{S'}P_X(S'\mid S)V_X(S').
\]

将所有可达状态联立得到

\[
(I-P_X)V_X=C_X.
\]

若矩阵奇异或无有限解，则该固定策略会导致坏件拆解回流后反复装配、无法交付合格成品，标记为不可行。初始状态期望成本为 `E[C|X]=V_X(S0)`，期望利润为

\[
E[\Pi(X)]=R-V_X(S_0),
\]

优化目标为 `X*=argmax E[Pi(X)]`。

### 11.4 求解算法

搜索空间 `65536` 个策略可全枚举，但每个策略都要建立并求解一个有限状态线性方程组，因而同时实现遗传算法：

- 染色体即 16 位策略编码；适应度为解析期望利润 `E[Pi(X)]`；
- 随机初始化 100 个个体的种群，锦标赛选择、单点交叉（概率 0.8）、按位变异（概率 0.02）、每代保留精英 5 个；
- 进化 200 代，独立运行 20 次（种子 2024--2043）以考察随机搜索稳定性；
